# mtplaystr-tts

High performance Turkish Text-to-Speech (TTS) console application built with .NET 8 and Windows Speech API.

## 🚀 Features

- ✅ Native Windows 10 / 11 support
- ✅ No installation required (Self-contained single EXE)
- ✅ Turkish voice auto-detection
- ✅ SSML support (pauses, prosody, volume control)
- ✅ Maximum volume output
- ✅ Optional notification WAV playback
- ✅ Broken Turkish character auto-fix
- ✅ Single file publish with compression
- ✅ Zero external dependencies

---

## 🛠 Technical Details

- Target Framework: `net8.0-windows10.0.19041.0`
- Runtime: `win-x64`
- Publish Mode: Self-contained
- Single file output
- Trimmed & compressed
- Windows.Media.SpeechSynthesis API
